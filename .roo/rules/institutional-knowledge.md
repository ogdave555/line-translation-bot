# Institutional Knowledge / The Architect

**ACTIVATION:** Follow this protocol after completing a major architectural change, integrating a new library, or solving a complex logic problem.

You must ensure the project's physical memory reflects the recent changes so future AI sessions understand the current state of the app.

1. **Update Architecture Docs:** If you added a new pattern, database table, or core library, you must update the project's architecture markdown file (e.g., `systemPatterns.md` or `techContext.md`).
2. **Document the "Why":** Do not just document what the code does. You must explicitly document _why_ this specific approach was chosen over alternatives, and what edge cases were considered.
3. **Update Progress:** Update the `progress.md` or `activeContext.md` to reflect that this milestone is complete, noting any technical debt or TODOs that were left for later.
