# Thai-English Translation Glossary

## Thai Pragmatic Particles

| Thai | Meaning | English Rendering |
|------|---------|------------------|
| ค่ะ / คะ | Polite particle (female) | Softener: "please", "xx", gentle emoji |
| ค่า | Soft emphasis (female) | "yeah", "ok", trailing softener |
| นะ | Soft request/emphasis | "please", "ok", trailing softener |
| ่ะ (ะ) | Casual imperative | Direct but not harsh |
| จ้า | Friendly assertion | "yeah", "alright", "you know" |
| เนอะ | Agreement/confirmation | "right", "yeah", "exactly" |
| ฮะ | Soft question (male) | "hmm", "really?" |
| อ่ะ / อ่ | Hesitation/filler | "um", "well", "like" |

## Thai Register Levels

### Formal → Casual Spectrum

| Register | Thai Examples | When to Use |
|----------|---------------|-------------|
| Formal | อรุณสวัสดิ์, ขอบคุณครับ/ค่ะ | NEVER for casual chat (overly formal) |
| Polite | สวัสดีค่ะ, ขอบคุณ | Service context |
| Casual | ไง, ดีจ้า, เราไปกัน | Close relationship |
| Very Casual | หวัด, ไอ้, มึง | Intimate/casual LINE chat |

**KEY RULE:** Avoid formal greetings like อรุณสวัสดิ์ in casual chat. Use ไง, หวัด, ฮาย instead.

## Post-Translation Guard

After translation, the output is checked by `validateOutputScript()` in
`src/core/config.ts`. If the output contains a word in the wrong script
that does NOT appear in the source text, the output is REJECTED and the
cascade falls through to the next provider. Legitimate preserved tokens
(names, URLs, `[PROFANITY:N]` markers) pass through because they appear
in the source.
